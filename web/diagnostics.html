      Ports that must be open

      Video and audio travel straight between guests and this server over UDP, never through the web page's own connection. A reverse proxy, a Cloudflare tunnel or an SSH tunnel carries the pages only, so these ports still need to reach this machine directly. On a home server that means forwarding them on your router.
